Instant Certificate Authority

A zero-dependency, lightning-fast CA generator built in Go. Secure your microservices, RPC endpoints, and local development environments in seconds.

Usage & Examples

1. Generate a Server Certificate

To generate a leaf certificate valid for a specific domain, run:

goselfca --domains "myserver.internal"

This creates a root CA (if one doesn't exist) and outputs your keys into a myserver.internal/ directory.

2. Multiple Domains & IP Addresses

You can comma-separate domains and IPs to embed them as Subject Alternative Names (SANs).

goselfca --domains "db1.local,db2.local" --ip-addresses "192.168.1.50"

3. Client & Peer Authentication

Generate certificates tailored for mTLS (mutual TLS) by changing the profile.

goselfca --domains "worker-node-1" --profile client

Available profiles: server, client, peer.

Configuration Flags

Flag Default Description
--domains None Comma-separated domain names for SANs.
--ip-addresses None Comma-separated IP addresses for SANs.
--ca-alg ed25519 Algorithm for new keypairs (RSA, ECDSA, Ed25519).
--profile server Type of certificate (server, client, peer).
--validity ~2 years Validity duration of the leaf certificate (e.g., 8760h).
--org None Organization (O) field for the certificate subject.
